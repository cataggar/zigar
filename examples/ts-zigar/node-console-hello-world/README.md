# `node-console-hello-world` (`ts-zigar`)

End-to-end **Node.js 26 Active LTS (`@types/node@26`)** console and CLI argument example in Zig 0.17, mirroring [`taggartsoftware/ts2rs/node-console-hello-world`](https://github.com/taggartsoftware/ts2rs/tree/master/node-console-hello-world).

`src/console.zig` imports the shared `@import("node")` bindings generated by `zigar ts` (`../node`), reads `process.argv` into a Zig slice (`[]const []const u8`), formats a greeting, and logs both to `console.log`—running unmodified on **WebAssembly** (`rollup-plugin-zigar`) and **native `node-zigar`**.

## Quick Start

1. Generate the shared `@types/node@26` Zig bindings (cached after first run):
   ```bash
   npm run generate
   ```

2. Build and run on **WebAssembly** (`rollup-plugin-zigar`):
   ```bash
   npm run build:wasm
   npm run run:wasm -- "World" --example-arg
   ```

3. Run natively via **`node-zigar`** (compiles `src/console.zig` to a native shared library):
   ```bash
   npm run run:native -- "World" --example-arg
   ```

4. Run the automated WASM + native test suite (verifying output, bundle tree-shaking, and `activeHandles === 0`):
   ```bash
   npm test
   ```
