# `node-server-hello-world` (`ts-zigar`)

End-to-end **Node.js 26 Active LTS (`@types/node@26`)** HTTP server example in Zig 0.17, mirroring [`taggartsoftware/ts2rs/node-server-hello-world`](https://github.com/taggartsoftware/ts2rs/tree/master/node-server-hello-world).

`src/server.zig` imports the shared `@import("node")` bindings generated by `zigar ts` (`../node`), reads `process.env.PORT` (default `3000`, or `0` for an ephemeral OS port), registers managed Zig `Closure` listeners with `node.http.createServer` and `server.listen`, responds `200 OK` (`text/plain; charset=utf-8`, `"Hello, World!\n"`) using `IncomingMessage` and `ServerResponse`, and provides deterministic `shutdown()` cleanup—running unmodified on **WebAssembly** (`rollup-plugin-zigar`) and **native `node-zigar`**.

## Quick Start

1. Generate the shared `@types/node@26` Zig bindings (cached after first run):
   ```bash
   npm run generate
   ```

2. Build and run on **WebAssembly** (`rollup-plugin-zigar`):
   ```bash
   npm run build:wasm
   PORT=3000 npm run run:wasm
   ```

3. Run natively via **`node-zigar`**:
   ```bash
   PORT=3000 npm run run:native
   ```

4. Run the automated WASM + native integration tests (verifying live loopback `fetch()`, bundle tree-shaking to `node:http` only, graceful shutdown, and `activeHandles === 0` / `activeCallbacks === 0`):
   ```bash
   npm test
   ```
