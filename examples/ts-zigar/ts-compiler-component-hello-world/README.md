# TypeScript 7.1 Go WASM Component Hello World (`ts-zigar`)

Standalone end-to-end example calling the **TypeScript 7.1 Go WebAssembly Component** (`zigar:typescript@7.1.0/compiler`) from **Zig 0.17** using WIT bindings generated by `zigar wit` (`wit-zigar`).

The exact same Zig compiler pipeline (`src/lib.zig`) runs in **two execution modes**:

1. **Native Zig** (`zig build run` / `zig build test`) — Zig drives `typescript-compiler.component.wasm` via `wit-zigar`'s `ComponentHost` + `NodeProcessBackend` (Node.js 26 V8 WebAssembly host).
2. **WebAssembly Guest in Node.js 26** (`node run-wasm.mjs` / `npm test`) — `zigar-compiler` compiles `src/lib.zig` to `wasm32-wasi` and connects it to `instantiateComponentHost(...)` across separate WebAssembly linear memories via `createEnvironment()`.

## Prerequisites

- **Zig 0.17**
- **Node.js 26+**
- **Go + `componentize-go`** (only required on the first run if `ts-zigar/component/dist/typescript-compiler.component.wasm` has not been built yet)

## Quick Start

From `examples/ts-zigar/ts-compiler-component-hello-world/`:

### 1. Build the TypeScript 7.1 Go WASM Component (automatic)

Both `zig build` and `run-wasm.mjs` invoke `../../../ts-zigar/component/build-component.mjs` automatically when `ts-zigar/component/dist/typescript-compiler.component.wasm` is missing. You can also build it explicitly:

```bash
zig build component
# or directly:
node ../../../ts-zigar/component/build-component.mjs
```

Set `TS_ZIGAR_CACHE_DIR` to share the pinned upstream TypeScript source checkout across builds/worktrees.

### 2. Generate Zig 0.17 WIT Bindings (`zigar wit`)

`build.zig` and `src/build.extra.zig` generate bindings automatically at build time. To inspect the generated Zig 0.17 bindings directly:

```bash
zig build wit
# Emits: zig-out/wit/generated_ts.zig

# Or via the zigar CLI:
node ../../../zigar-compiler/bin/cli.js wit \
  ../../../ts-zigar/wit/typescript.wit \
  --world typescript-compiler \
  -o generated_ts.zig
```

### 3. Run Natively from Zig

```bash
zig build run
zig build test
```

### 4. Run Compiled to WebAssembly in Node.js 26

```bash
node run-wasm.mjs
node --test test/node-runner.test.mjs
# or: npm test
```

## What `src/lib.zig` Demonstrates

1. **Compiler version** — Calls `compiler.compilerVersion()` (`7.1.0-...`).
2. **In-memory VFS** — Creates `vfs` via `compiler.createVfs(scratch, true)` (with bundled `lib.*.d.ts`) and mounts `/app/math.ts` + `/app/index.ts` featuring generics, union types, mapped types, `async`/`Promise`, and cross-file ES imports.
3. **Strict compilation** — Calls `compiler.createProgram(...)` with `strict`, `exactOptionalPropertyTypes`, and `noUncheckedIndexedAccess`, verifying **0 syntactic** and **0 semantic** diagnostics.
4. **Interactive `checker` queries** — Acquires `program.getChecker()`, inspects `summarizeBatch`'s inferred signature with `checker.typeToString(...)`, and enumerates module exports via `checker.resolveModuleExports(...)`.
5. **Declaration emit & JS transpilation** — Emits `.d.ts` files with `program.emitDeclarations(...)` and transpiles TypeScript to JavaScript via `compiler.transpileModule(...)`.
6. **Semantic error reporting** — Compiles `/app/broken.ts` containing an intentional type error (`export const invalidReading: number = "not-a-number"`), queries `broken_program.getSemanticDiagnostics(...)`, and verifies `TS2322`, file path, 1-based line/column, and diagnostic message.
7. **Deterministic WIT resource & memory cleanup** — Drops all WIT handles and verifies `host.liveResourceCount() == 0` with zero Zig `DebugAllocator` (GPA) leaks.

## WIT Resource Lifecycle (`vfs`, `program`, `checker`)

WIT resources live inside the component host's handle table until explicitly dropped. Always pair creation with `defer ...deinit()` for error-path safety, and drop child resources in reverse creation order (`checker` -> `program` -> `vfs`):

```zig
const compiler = bindings.compiler.bindHost(host);

var vfs = try compiler.createVfs(scratch, true);
defer vfs.deinit(); // idempotent cleanup if an early error occurs

const prog_res = try compiler.createProgram(scratch, vfs.asBorrow(), &root_files, opts);
var program = compiler.wrapProgram(prog_res.ok);
defer program.deinit();

var checker = compiler.wrapChecker(try program.getChecker(scratch));
defer checker.deinit();

// ... use checker, program, and vfs ...
// Free Canonical ABI lifted values with `ch.freeValue(T, scratch, value)`.

// Explicit reverse-order drop (deinit() becomes a no-op afterwards):
try checker.drop();
try program.drop();
try vfs.drop();
std.debug.assert(host.liveResourceCount() == 0);
```
