# `ts-zigar` Examples

End-to-end Zig 0.17 examples generated by **`ts-zigar`** (`zigar ts`) and **`wit-zigar`** (`zigar wit`), targeting **Node.js 26 Active LTS** (`@types/node@26`), **Monaco Editor** (`monaco-editor` + `lib.dom.d.ts`), and the **TypeScript 7.1 Go WebAssembly Component** (`zigar:typescript@7.1.0`).

## Examples Overview

| Directory | Target | Description | Run / Test |
| --- | --- | --- | --- |
| [`node/`](./node/) | Node.js 26 (`@types/node@26`) | Generates Zig 0.17 bindings across all 71 `@types/node@26` entrypoints into `src/node/` with zero `AstGen` or fallback errors (`total_fallbacks == 0`). Shared by the Node.js examples below. | `node generate.mjs` |
| [`node-console-hello-world/`](./node-console-hello-world/) | Node.js 26 (Native N-API + WASM) | Calls `console.log`, `console.time`/`timeEnd`, `process.version`, `process.platform`, and `process.arch` from Zig with Rollup tree-shaking (`0` unused `node:*` imports). | `npm start`<br>`npm test` |
| [`node-server-hello-world/`](./node-server-hello-world/) | Node.js 26 (Native N-API + WASM) | HTTP server written in Zig using `node:http` (`createServer`, `IncomingMessage`, `ServerResponse`, `Closure` callbacks, graceful shutdown, and zero leaked handles/callbacks). | `npm start`<br>`npm test` |
| [`ts-compiler-component-hello-world/`](./ts-compiler-component-hello-world/) | Native Zig + Node.js 26 WASM | Drives the TypeScript 7.1 Go WASM Component (`zigar:typescript@7.1.0/compiler`) from Zig 0.17 via `zigar wit` (`createVfs`, `createProgram`, `getChecker`, `.d.ts` emit, JS transpilation, and `TS2322` diagnostics). | `zig build run`<br>`npm start`<br>`npm test` |
| [`monaco-editor/`](./monaco-editor/) | Browser / ESM (`monaco-editor` + DOM) | Generates linked `src/dom/` (`lib.dom.d.ts`) + `src/monaco/` (`monaco-editor/esm/vs/editor/editor.api.d.ts`) Zig bindings with `total_fallbacks == 0`, exercising `editor.create`, `getModel`, `onDidChangeModelContent`, `setModelMarkers`, `KeyMod.CtrlCmd \| KeyCode.KeyS`, and `MonacoEnvironment.getWorker`. | `npm run generate`<br>`npm test` |
| [`monaco-editor-hello-world/`](./monaco-editor-hello-world/) | Browser (`rollup-plugin-zigar` + Vite) | Interactive browser TypeScript Playground written in Zig (`src/app.zig` -> WASM) using `monaco-editor` + linked DOM bindings, live cursor/line telemetry, diagnostics markers, and `Ctrl/Cmd+S` formatting/action handling. | `npm run dev`<br>`npm run build`<br>`npm test` |
| [`gcloud-appengine-node26/`](./gcloud-appengine-node26/) | Google App Engine (`runtime: nodejs26`) + Cloud Run | Production HTTP service written in Zig (`node:http` + `node:timers/promises` + WebCrypto SHA-256) with `PORT` binding, `/_ah/warmup`, structured Cloud Logging JSON (`logging.googleapis.com/trace`), `SIGTERM` graceful drain, and WASM JSPI / Native N-API parity. | `npm run build:wasm`<br>`npm start`<br>`npm test` |
| [`aws-lambda-node26/`](./aws-lambda-node26/) | AWS Lambda (`nodejs26.x`, AL2023) + Elastic Beanstalk | Async API Gateway HTTP API v2 handler written in Zig (`@types/aws-lambda` + `@types/node@26`) with stripped JSPI WASM (`< 256 KiB`) + standalone native `WorkQueue` bundle, base64 binary decoding, X-Ray trace propagation, and `AWS_LAMBDA_LOG_FORMAT=JSON` telemetry. | `zig build test`<br>`npm run build:wasm`<br>`npm test` |
| [`azure-functions-node26/`](./azure-functions-node26/) | Azure Functions v4 (`NODE\|26`) + Azure App Service | Azure Functions v4 Programming Model HTTP triggers (`app.http` + `app.get`, `HttpRequest`, `HttpResponse`, `Cookie`, `InvocationContext`, Application Insights telemetry) written in Zig (`@azure/functions` + `@types/node@26`) with stripped JSPI WASM + standalone native `WorkQueue` parity. | `zig build test`<br>`npm run build:wasm`<br>`npm test` |

## Prerequisites

- **Zig 0.17** on `PATH`
- **Node.js 26+** (`npm`)
- **Go 1.26+ & `componentize-go`** *(required only if `ts-zigar/component/dist/typescript-compiler.component.wasm` has not been built yet; all example `generate.mjs` / `build.zig` scripts build it automatically when needed)*

## Running All Test Suites

```bash
npm --prefix examples/ts-zigar/node-console-hello-world test
npm --prefix examples/ts-zigar/node-server-hello-world test
npm --prefix examples/ts-zigar/ts-compiler-component-hello-world test
npm --prefix examples/ts-zigar/monaco-editor test
npm --prefix examples/ts-zigar/monaco-editor-hello-world test
npm --prefix examples/ts-zigar/gcloud-appengine-node26 test
npm --prefix examples/ts-zigar/aws-lambda-node26 test
npm --prefix examples/ts-zigar/azure-functions-node26 test
```
