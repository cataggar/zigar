# `monaco-editor` — Browser DOM Subset & Monaco Editor Zig 0.17 Bindings (`ts-zigar`)

Shared browser DOM (`dom.d.ts`) and [`monaco-editor`](https://www.npmjs.com/package/monaco-editor) Zig 0.17 bindings package generated by **`zigar ts`** (`ts-zigar`), mirroring `taggartsoftware/ts2rs/monaco-editor` and consumed by downstream browser examples such as `monaco-editor-hello-world`.

## Highlights

- **Modular, Bundler-Tree-Shaken `monaco-editor` Graph**: Runs `zigar ts` against `./dom.d.ts` and `./node_modules/monaco-editor` (`-s "monaco-editor=monaco"`), preserving fine-grained ESM wire specifiers (`"monaco-editor/editor/editor.api.js"`) so Rollup / Vite only bundle the exact Monaco entrypoints referenced by Zig (`@import("web").monaco.editor.create(...)` does not pull in unused language registration bundles).
- **Single-File `monaco.d.ts` Compatibility**: Also supports generating directly from Rollup-bundled `node_modules/monaco-editor/monaco.d.ts` (`-t ./dom.d.ts -t ./node_modules/monaco-editor/monaco.d.ts -s "monaco-editor/monaco=monaco"`).
- **Zero `unresolved_type_ref` Fallbacks**: `dom.d.ts` provides W3C / TypeScript 7.1 `lib.dom.d.ts`-compatible declarations (`Window`, `Document`, `HTMLElement`, `DocumentFragment`, `Worker`, `KeyboardEvent`, `MouseEvent`, `ClipboardEvent`, `WebSocket`, `URL`, etc.) so every Monaco API type resolves to concrete Zig structs, enums, unions, and `Ref(T)` handles.
- **`MonacoEnvironment` Worker Configuration from Zig**: `monaco.Environment.init()` + `setGetWorkerUrl(&closure)` / `setGetWorker(&closure)` + `monaco.monaco_environment.set(env)` lets Zig configure Monaco web workers without writing JavaScript glue.

## Quick Start

### 1. Install `monaco-editor` & Generate Zig Bindings

```bash
npm install
npm run generate
```

Equivalent `zigar ts` CLI invocation:

```bash
npx zigar ts \
  -t ./dom.d.ts \
  -t ./node_modules/monaco-editor \
  -s "monaco-editor=monaco" \
  -d ./generated
```

### 2. Compile & Check Bindings with Zig 0.17

```bash
zig build test --summary all
```

### 3. Run Binding-Level WASM + Native `node-zigar` Tests

```bash
npm test
```

> Note: `test/monaco.test.mjs` combines real `monaco-editor` `editorBaseApi.js` primitives (`Uri`, `Range`, `Position`, `Selection`, `KeyMod`, `KeyCode`, `MarkerSeverity`) with lightweight headless `editor`/`languages` stubs for fast binding verification. For full Vite + `rollup-plugin-zigar` browser bundling and real `monaco.editor.create` DOM mounting in JSDOM, see [`../monaco-editor-hello-world`](../monaco-editor-hello-world).

## Example Usage in Zig (`@import("web")`)

```zig
const std = @import("std");
const zigar = @import("zigar");
const web = @import("web");
const dom = web.dom;
const monaco = web.monaco;
const js = zigar.js;

const WorkerSetup = struct {
    pub fn getWorkerUrl(_: *const @This(), _: []const u8, label: []const u8) []const u8 {
        if (std.mem.eql(u8, label, "typescript") or std.mem.eql(u8, label, "javascript")) {
            return "./ts.worker.js";
        }
        return "./editor.worker.js";
    }
};

const WorkerClosure = js.Closure(*const WorkerSetup, WorkerSetup.getWorkerUrl);
var worker_setup: WorkerSetup = .{};
var worker_closure: ?WorkerClosure = null;

pub fn mountEditor() !void {
    var next_url = try WorkerClosure.tryInit(&worker_setup);
    {
        errdefer next_url.deinit();

        const env = try monaco.Environment.init();
        defer env.deinit();
        try env.setGetWorkerUrl(&next_url);
        try monaco.monaco_environment.set(env);
    }
    if (worker_closure) |*prev| prev.deinit();
    worker_closure = next_url;

    const doc = try dom.document.get();
    defer doc.deinit();
    const container = (try doc.getElementById("container")) orelse return error.ContainerNotFound;
    defer container.deinit();

    const editor = try monaco.editor.create(container, .{
        .value = "const answer: number = 42;\n",
        .language = "typescript",
        .theme = "vs-dark",
        .automatic_layout = true,
    }, null);
    defer editor.deinit();
}
```
