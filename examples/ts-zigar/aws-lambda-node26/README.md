# `aws-lambda-node26` — Zig AWS Lambda `nodejs26.x` Handler (`ts-zigar`)

Serverless Zig handler targeting **AWS Lambda `nodejs26.x`** (Amazon Linux 2023) using combined `@types/aws-lambda` + `@types/node@26` bindings generated by `ts-zigar`.

## Cloud Runtime Matrix

| Target | Runtime / OS | Deployment Artifact | Entrypoint |
| --- | --- | --- | --- |
| **AWS Lambda Managed Runtime** | `nodejs26.x` (Amazon Linux 2023, `x86_64` / `arm64`) | `index.mjs` + `dist/lambda.mjs` (self-contained WASM + WebAssembly JSPI, zero `node_modules` at runtime) | `index.handler` |
| **AWS Lambda Custom Container / AWS Elastic Beanstalk** | Node.js 26 (`public.ecr.aws/lambda/nodejs:26` / AL2023) | `index-native.mjs` + `dist/native/` standalone `node-zigar` native bundle (`WorkQueue` async, zero runtime `node_modules`) | `index-native.handler` |

## Features Exercised from Zig

- **Typed `@types/aws-lambda` bindings (`generated/aws_lambda/*`)**:
  - `ApiGatewayProxyEventV2.fromJsRefAlloc` (HTTP API v2 event, `requestContext.http`, headers, query parameters, cookies, and base64-encoded binary bodies)
  - `Context.fromJsRef` (`awsRequestId`, `functionName`, `functionVersion`, `memoryLimitInMB`, `getRemainingTimeInMillis()`)
  - `ApiGatewayProxyStructuredResultV2.toJsRef` (`statusCode`, `headers`, `cookies`, `body`, `isBase64Encoded`)
  - Full compile-time verification of `@types/aws-lambda` triggers including recursive `DynamoDB.AttributeValue`, `S3Event`, `SQSEvent`, and `ALBEvent` (`zig build test`)
- **Async `@types/node@26` APIs across JSPI / `WorkQueue` suspension**:
  - `node:crypto` WebCrypto `crypto.subtle.digest("SHA-256", ...)` awaiting a real JS `Promise<ArrayBuffer>`
  - `node:buffer` `Buffer.from(body, "base64")` for binary API Gateway payloads
  - `node:timers/promises` `setTimeout`
  - Optional CloudWatch structured JSON telemetry (`AWS_LAMBDA_LOG_FORMAT=JSON`) with `X-Amzn-Trace-Id` correlation

## Quick Start

```bash
npm install
npm run build:wasm     # generates @types/aws-lambda + @types/node@26 bindings and builds stripped dist/lambda.mjs
npm run build:native   # builds standalone native dist/native/ bundle (lambda.zigar + node-zigar-addon)
zig build test         # compile-checks generated @types/aws-lambda + @types/node@26 Zig module graph
npm test               # runs WASM JSPI + CloudWatch JSON + standalone native node-zigar WorkQueue tests
```

## Packaging for AWS Lambda (`nodejs26.x`)

After `npm run build:wasm`, zip only `package.json`, `index.mjs`, `dist/lambda.mjs`, and `dist/assets/` (`< 256 KiB` stripped WASM, zero runtime `npm` dependencies):

```bash
npm run build:wasm
zip -r function.zip package.json index.mjs dist/lambda.mjs dist/assets/
aws lambda create-function \
  --function-name ts-zigar-aws-lambda-node26 \
  --runtime nodejs26.x \
  --architectures arm64 \
  --handler index.handler \
  --zip-file fileb://function.zip \
  --role arn:aws:iam::<ACCOUNT_ID>:role/<LAMBDA_EXECUTION_ROLE>
```
